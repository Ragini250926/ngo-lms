# NGO Learn — LMS for NGOs

Phase 1 is the frontend foundation of the academic B.Sc. IT project.

## Technology
- Python
- Flask
- HTML5
- CSS3
- JavaScript

## Run on Windows

1. Open this folder in Visual Studio.
2. Open Terminal / PowerShell.
3. Create a virtual environment:

   python -m venv venv

4. Activate it:

   venv\Scripts\activate

5. Install Flask:

   pip install -r requirements.txt

6. Start the application:

   python app.py

7. Open:

   http://127.0.0.1:5000

The SQLite database will be added in Phase 2.

## Phase 1
This phase contains the complete public/user/admin page structure and responsive design. Authentication, database operations, enrollment, quizzes and certificates become functional in later phases.
